# Mini Device Monitor
## Project Introduction
- Why This Project?

    It's just a little project which a beginner learning C wanna to improve his programming skills but he don't like just solving problem sets repeatedly. It's also an attempt to experience the real-world development.
    Or: I'm learning C, and I want to improve my programming skills by building practical projects instead of only solving problem sets.
## Features
- Temperature Analysis

    We can calculate the average, and find the maximum and the minimum.
    Count abnormal temperature readings.
## How to run

Compile the program with Clang:

```bash
clang main.c -o monitor
```

Run the program:

```bash
./monitor
```
